📖 点击查看小白一键授权教程 (无需手动建库)

1. 点击专属生成链接（全套读写权限已帮您预勾选好）：
👉 点击一键生成 GitHub Token

2. 复制密钥：
打开页面后直接拉到最底部，点击 Generate token，复制生成的代码（以 ghp_ 开头）。

3. 粘贴绑定：
贴在下方输入框点击【验证并绑定】。若您账号下没有仓库，系统会自动调用 API 帮您创建仓库并保存！

⚠️ 检测到重复徽章（请抉择保留项）
💡 任君选择：检测到您勾选的徽章中存在同概念重复的情况，请为以下冲突点选您想保留的徽章版本：

1. Icon Style (图标风格)

Colored (彩色彩色)
Mono (单色黑白)

2. HDR Display (HDR 显示策略)

Only when no DV (无 DV 时才显示 HDR)
Always (总是显示 HDR)

3. Badge Spacing (徽章排列间距)

Tight (极窄 2px)
Standard (标准 5px)
Relaxed (宽松 8px)
Wide (宽距 12px)

4. Description (描述栏排版)

Service + Filename (服务商 + 文件名)
Filename Only (仅显示文件名)

5. Import Custom Badges JSON (导入自定义 JSON / 网址)

粘贴第三方 URL 网址（如 xperience-app 链接）或您的 JSON 代码，合并时会自动智能归类（以紫色高亮区分）。

6. Badge Manager (全徽章分类勾选与管理面板)

杜比 5 大音视频、DTS 4 大音效已完美隔离。紫色字代表新导入徽章。

All Active Badges Gallery (生效徽章分类平铺大图鉴)

展现当前勾选生效的所有徽章列表（已按类别分类呈现）。
